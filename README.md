# Hairline Catalogue

An interactive card-catalogue cabinet drawn as an isometric line figure, in the style of [@lucasmarkes/hairline](https://github.com/lucasmarkes/hairline).

Hover a drawer: it slides out and an index card rises from it. The slider sets how high the card rises, and the switch changes between the light and dark themes.

- `catalogue-card.html` is the finished page: open it in any browser, nothing to install.
- `catalogue.js` is the figure's source.
- `card-template.html` is the card layout the page is built from.
- `hairline-catalogue.html` is the figure on Hairline's standard test page.
